# SupCrud Widget

Widget embebible para integrar soporte PQRS de SupCrud en cualquier sitio web.

---

## Instalación

Agrega el siguiente script antes del cierre de tu `<body>`.

```html
<script 
src="https://crudzaso.github.io/supcrud-widget/widget.js"
data-workspace="WORKSPACE_KEY">
</script>
```

Reemplaza `WORKSPACE_KEY` con la clave de tu workspace.

---

## Ejemplo

```html
<script 
src="https://crudzaso.github.io/supcrud-widget/widget.js"
data-workspace="abc123">
</script>
```

---

## Qué hace el widget

El widget permite a los usuarios:

- Crear tickets de soporte
- Rastrear tickets con un referenceCode
- Adjuntar archivos (si el add-on está activo)

---

## Tecnologías

- JavaScript Vanilla
- fetch API
- CSS inyectado dinámicamente
